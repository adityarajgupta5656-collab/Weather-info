# Weather-info
This application allows users to search  weather details of any city, including temperature, humidity, wind speed, and  weather conditions.

# Objectives of the Project: 
• To provide real-time weather information 
• To develop a responsive web application 
• To understand API integration 
• To improve front-end development skills 
• To create an interactive and user-friendly interface

# Technologies Used: 
• HTML 
• CSS 
• JavaScript 
• Bootstrap 
• OpenWeather API

# Working of the Project: 
When the user enters a city name, the application fetches weather data from the API using JavaScript. The weather details such as temperature, humidity, wind speed, and weather condition are displayed on the screen instantly
